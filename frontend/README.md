# Frontend Recetas LLM

Interfaz Vue + Vite para gestionar inventario, generar recetas con el LLM y revisar el historial.

## Comandos

```bash
npm install
npm run dev
npm run build
```

La URL del backend se configura con `VITE_API_BASE_URL`.

## Capturas pendientes para el PDF

- Inicio en desktop, con el modal de acceso abierto desde el boton principal.
- Login o registro.
- Inventario vacio y luego inventario con ingredientes.
- Receta recien generada, incluyendo el estado de carga si se alcanza a capturar.
- Historial con busqueda, filtro de dificultad y calificacion visible.
- Detalle de receta.
- Perfil con sesion activa.
- Vista mobile de inicio, inventario e historial en 360px de ancho.
